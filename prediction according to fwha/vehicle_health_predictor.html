How this is computed: Chassis formulas (rollover threshold = track/2h, braking efficiency = decel ÷ friction demand, etc.) use geometry defaults for a common Indian rigid bus — the shared range across Tata Starbus, Ashok Leyland Viking, and AIS-052/CMVR body-code limits: wheelbase ~5.2-6.0m, track ~1.85-2.15m, laden CG ~1.0-1.6m, single rigid unit. Identical formulas to vehicle_health_model.h. Engine health uses a logistic regression trained on 19,535 real rows of engine sensor data — identical to engine_health_model.h. Combined score is a 50/50 average. Rollover/offtracking targets are provisional and self-consistent with this geometry, not confirmed AIS-031 benchmarks — validate against real bus data before relying on this for safety decisions.
